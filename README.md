# 🎵 Invasores Musicais 👾

Uma recriação do clássico jogo de arcade *Space Invaders* com um toque musical. Em vez de alienígenas, o jogador enfrenta hordas de figuras musicais — Semibreve, Mínima, Semínima, Colcheia e Semicolcheia — que descem pela tela. As barreiras de defesa também são substituídas por essas figuras, criando uma experiência temática única e divertida.

O jogo é construído inteiramente com **HTML5 Canvas** e **JavaScript** puro, sem a necessidade de frameworks externos, e inclui efeitos sonoros gerados com a biblioteca **Tone.js** para uma maior imersão.

## ✨ Funcionalidades

* **Jogabilidade Clássica:** Ação de tiro inspirada no icônico *Space Invaders*.
* **Tema Musical:** Inimigos e barreiras são representados por figuras musicais.
* **Níveis Progressivos:** A dificuldade aumenta a cada nível concluído.
* **Pontuação e Vidas:** Sistema de pontuação e vidas para acompanhar seu progresso.
* **Alvo musical:** Acerte a figura indicada para ganhar bônus crescente a cada acerto consecutivo. Um acerto em outra figura ou a perda de uma vida encerra a sequência.
* **Recorde local:** A maior pontuação fica salva no navegador.
* **Pausa e som:** Pause com P ou pelo botão e silencie a trilha e os efeitos quando quiser.
* **Controles Responsivos:** Jogue no desktop com o teclado (`Setas` para mover, `Espaço` para atirar) ou em dispositivos móveis com controles de toque.
* **Efeitos Sonoros:** Sons gerados em tempo real para tiros e colisões.

## 🚀 Como Jogar

1.  Clone ou baixe este repositório.
2.  Abra o arquivo `index.html` (ou o nome que você deu ao arquivo HTML) em qualquer navegador moderno.
3.  Pressione o botão "Iniciar Jogo" e divirta-se!
